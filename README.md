# 🧹 房務整理看板 (Housekeeping Dashboard) 設定與使用指南

這是一個專為房務人員設計的「唯讀資訊看板」網頁，採用高質感的**莫蘭迪色系**設計，支援手機直向瀏覽，並且能**自動讀取您在 Google Sheet 上的最新排班資料**！

---

## 🚀 如何與您的 Google Sheet 連動？

請跟著以下簡單的 **3 個步驟**，讓網頁自動讀取您的試算表：

### 步驟 1：在 Google 試算表啟用「發佈到網路」

1. 打開您的 Google Sheet 排班表。
2. 點擊左上角的 **「檔案 (File)」** ➔ **「共用 (Share)」** ➔ **「發佈到網路 (Publish to the web)」**。
3. 在彈出的視窗中：
   - 將第一個下拉選單從「整個文件」改為 **您排班的那一個工作表名稱**（例如：`工作表1` 或 `Sheet1`）。
   - 將第二個下拉選單從「網頁」改為 **「逗號分隔值 (.csv)」**。
4. 點擊 **「發佈 (Publish)」** 按鈕並確認。
5. **複製** 視窗中產生的那段 `https://docs.google.com/spreadsheets/d/.../pub?output=csv` 網址。

> ⚠️ **請放心**：這個操作只會產生一個唯讀的資料連結，任何人（包括本網頁）都**無法**修改您的 Google Sheet 原始檔案，安全性 100%。

---

### 步驟 2：將連結填入房務看板網頁

1. 用瀏覽器打開您的房務看板網頁 (`index.html`)。
2. 點擊畫面最下方的 **「⚙️ 設定 Google Sheet 連結」** 按鈕（或齒輪圖示）。
3. 將剛剛複製的 **CSV 連結** 貼入輸入框中。
4. 點擊 **「儲存並同步」**。
5. 網頁會自動下載並解析您的排班表，並將連結儲存在瀏覽器中。**以後打開網頁都不需要再貼一次了！**

---

### 步驟 3：房務人員如何使用？

1. **選擇自己名字**：網頁頂部有一個下拉選單「👤 選擇人員」，房務員點擊後選擇自己的名字（例如「華」或「姐」），網頁就會一鍵篩選出今天所有分配給他的房間。
2. **看懂卡片顏色**：
   - 🛏️ **續住整理 (代號 1)**：以**莫蘭迪藍灰色**顯示，代表簡單整理。
   - 🔑 **退房整理 (代號 2)**：以**莫蘭迪煙粉色**顯示，代表需要深層清潔（換床單、備品等）。
   - 📊 **今日工作摘要**：網頁最上方會顯示今天的 `大` 與 `小` 統計值，方便房務員出發前準備對應的備品數量。
3. **切換日期**：預設為今天，但可以點擊日期選擇器查看明天或昨天的排班。

## 🎨 莫蘭迪色系設計說明 (Morandi Aesthetic)

本網頁採用莫蘭迪高雅色調，極致舒適、防刺眼，適合房務人員長時間觀看：
*   **暖米白背景 (`#f5f2eb`)**：如棉麻質感的溫和底色，比刺眼純白更溫柔。
*   **鼠尾草綠 (`#b3c7ae`)**：代表乾淨、完成的意象。
*   **莫蘭迪藍 (`#a8b9c4`)**：續住整理，平靜優雅。
*   **莫蘭迪粉 (`#e2b4b0`)**：退房整理，溫和提醒。
*   **炭灰色字 (`#3c3c3c`)**：高對比讀取，陽光下也清晰可見。
